# 🎮 Jungle Escape Game (C# Desktop Application)

Jungle Escape Game is a desktop-based game developed in C# using Object-Oriented Programming principles.  
This project was built during my OOP course, where I also designed and implemented my own simple game framework.

---

## 🚀 Project Overview

Jungle Escape is a multi-level game where the player navigates through obstacles, collects items, avoids enemies, and reaches the exit to win.

The project focuses on:
- OOP design
- Modular architecture
- Game logic handling
- Custom framework implementation

---

## 🧠 Concepts Used

- Object-Oriented Programming (Encapsulation, Abstraction, Inheritance, Polymorphism)
- Custom Game Framework
- Event Handling
- Game State Management
- Clean Code Structure

---

## 🎯 Features

- Player movement system
- Enemy (ghost) movement logic
- Multiple levels
- Collectibles system
- Win / Lose conditions
- Score tracking
- Modular and reusable classes

---

## 🛠 Tech Stack

- Language: C#
- Platform: .NET (Desktop Application)
- IDE: Visual Studio
- Architecture: Custom OOP-Based Framework

## 📂 Project Structure

- Enemy Class
